## 上游

同步到 Telegram iOS 13.0.0。

- 新增钱包（Wallet）功能，入口由 Telegram 服务端按账号开放，未开放的账号暂不可见。
- 全新网络引擎与动态贴纸渲染后端。
- 密码锁设置重做。
- 视频消息相机、通话、富文本消息等多处改进。

## 新增

- 外部翻译服务：翻译后的消息保留原文的格式（粗体、链接、代码等）。
- 注册日期：改为本地 ID 表估算，不再依赖第三方接口。
- 设置搜索：可以搜到 Nagram 设置及其子页面里的选项，点击结果会跳到对应的选项并高亮；支持从中文词的中间开始匹配。
- 显示消息 ID：在群组和频道的消息气泡时间后显示消息 ID，默认关闭。
- 取消置顶前确认：取消单条消息置顶或取消所有置顶前先询问，默认关闭。
- 联系人列表：双向联系人后面显示双向箭头标记。
- 设置页：底栏隐藏了联系人时，设置里出现「联系人」入口；「最近通话」入口同样只在底栏没有通话时出现。

## 修复

- 外部翻译服务：同一条消息不再重复请求，同时发出的请求数量有上限。
- 翻译：单聊开启自动翻译时「显示原文」不生效、频道评论区未应用翻译设置的问题。
- 输入框：旧版输入框中多行引用不再被拆成多个引用块。
- 照片上传卡住的问题（停用 JPEG XL 实验）。
- 聊天顶部工具栏横向滑动不再误触发返回手势。
- 富文本消息里的视频上滑进入画中画后，画廊会正常关闭。
- 设置搜索：从搜索结果进入的设置页离开导航栈后，搜索状态不再残留。
- 设置搜索：没有结果时显示「无结果」，不再留着上一次搜索的结果。
- 设置页：以独立页面打开设置时，从里面进入聊天后返回会回到设置。
- 聊天列表：底栏只剩搜索按钮时，不再显示底部的渐隐遮罩。

## 注意

- 升级后本地数据库会迁移到 13.0 格式，无法降级回 12.9.x。
- 底栏搜索、会话导入、圆形视频默认摄像头在本版本中经过适配，如遇异常请反馈。
